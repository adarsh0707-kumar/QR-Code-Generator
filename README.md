# QR Code Generator 📱⚡

A clean, responsive, and lightweight web application built using HTML, CSS, and JavaScript that dynamically generates QR codes for any text, URL, or custom string in real time.

---

## 🚀 Features

- **Instant QR Code Generation:** Real-time generation of QR codes based on user input.
- **Responsive & Modern UI:** Optimized for desktop, tablet, and mobile screens.
- **Input Validation:** Prevents empty submissions with visual alerts/feedback.
- **Client-Side Processing:** Dynamic updates using lightweight JavaScript integration.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for optimal accessibility.
- **CSS3:** Custom styles, Flexbox layout, and responsive design media queries.
- **JavaScript (ES6):** DOM manipulation, user input handling, and QR API dynamic interaction.

---

## 💻 Getting Started

### Prerequisites

No complex installation or build setup is required! All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Local Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/adarsh0707-kumar/QR-Code-Generator.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd QR-Code-Generator
   ```

3. **Run the Application:**
   - Double-click `index.html` to open it directly in your web browser, **or**
   - Use the **Live Server** extension in Visual Studio Code for a hot-reloading experience.
