# Contributing to QR Code Generator 🤝

Thank you for your interest in contributing to the **QR Code Generator** project! Contributions from the community help make this project better for everyone.

---

## 🚀 How Can You Contribute?

### 1. Reporting Bugs
If you encounter a bug or unexpected behavior, please check open issues first. If it's new, open a bug report issue and include:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Expected vs. actual behavior.
- Browser and device details (e.g., Chrome on Windows 11).

### 2. Requesting Features
Have an idea for a feature (e.g., custom QR code colors, download button, logo overlay)? Feel free to create a feature request issue with:
- The motivation behind the feature.
- A clear description of what you'd like to see added.

### 3. Submitting Pull Requests (PRs)
1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork to your local environment:
   ```bash
   git clone https://github.com/YOUR-USERNAME/QR-Code-Generator.git
   ```
3. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make and Commit Your Changes:**
   Write clean, understandable commits with descriptive messages.
   ```bash
   git commit -m "Add: custom QR code download button functionality"
   ```
5. **Push to Your Fork:**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request:** Navigate to the original repository and open a PR against the `main` branch with a summary of your changes.

---

## 📏 Style Guidelines

- **HTML/CSS:** Maintain clean formatting, proper indentation (2 or 4 spaces), and clear class naming conventions.
- **JavaScript:** Follow ES6+ conventions, use descriptive variable names, and comment complex logic where appropriate.
